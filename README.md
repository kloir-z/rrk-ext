# 楽楽勤怠カスタマイザー

楽楽勤怠の出勤簿画面を使いやすくカスタマイズするEdge拡張機能です。

## 機能

### 1. 列の表示/非表示切り替え
- 40列以上ある出勤簿の列から、必要な列だけを表示できます
- 拡張機能のポップアップから簡単に設定可能
- 3つのプリセット（最小限、基本、すべて表示）を用意

### 2. ダブルクリックで編集モード起動
- 従来: チェックボックス選択 → 画面下の「編集をする」ボタンをクリック
- 改善後: 行をダブルクリックするだけで編集モードに入れます

### 3. 設定の自動保存
- 列の表示設定は自動的に保存され、次回アクセス時も適用されます

## インストール方法

1. **Edge拡張機能として読み込む**
   1. Edgeを開き、`edge://extensions/` にアクセス
   2. 右上の「開発者モード」をONにする
   3. 「展開して読み込み」ボタンをクリック
   4. このフォルダ (`C:\js\rrk-ext`) を選択

2. **楽楽勤怠にアクセス**
   - `https://tms.rakurakukintai.jp/app/attendance` にアクセス
   - 自動的にカスタマイズが適用されます

## 使い方

### 列の表示設定を変更する

1. Edgeのツールバーにある拡張機能アイコンをクリック
2. 表示したい列にチェックを入れる
3. 「保存」ボタンをクリック
4. ページが自動的に更新されます

### ダブルクリックで編集

1. 出勤簿の任意の行をダブルクリック
2. 自動的にチェックボックスが選択され、編集モードに入ります

### カスタム列を追加する（上級者向け）

楽楽勤怠のカスタマイズ機能で追加した会社独自の列を制御したい場合：

1. `content.js` と `popup.js` を開く
2. コメントアウトされているカスタム列の例を探す
   ```javascript
   // カスタム列の例：実際の列名に合わせて以下をコメント解除・修正してください
   // 'カスタム列1': false,
   ```
3. コメントを解除し、実際の列名に変更
   ```javascript
   '勤務パターン': false,  // 例：会社独自の列
   ```
4. 両方のファイルで同じ変更を行い、拡張機能を再読み込み

## ファイル構成

```
C:\js\rrk-ext\
├── manifest.json       # 拡張機能の設定ファイル
├── content.js          # メインのロジック（ページに注入）
├── popup.html          # 設定画面のHTML
├── popup.js            # 設定画面のロジック
└── styles.css          # カスタムスタイル
```

## トラブルシューティング

### 拡張機能が動作しない
- Edgeの開発者ツール（F12）でコンソールを確認
- 「楽楽勤怠カスタマイザー」で始まるログメッセージを確認

### 列が非表示にならない
- ページをリロード（F5）してみる
- 拡張機能を一度無効化してから再度有効化

### ダブルクリックが反応しない
- 編集可能な日付の行でダブルクリックしているか確認
- チェックボックスが無効になっている行では動作しません

## 技術仕様

- Manifest Version: 3
- 対象URL: `https://tms.rakurakukintai.jp/app/attendance`
- 実装言語: JavaScript (Vanilla)
